1. Convolutional Neural Networks (CNNs) Theory

Traditional Fully Connected Networks (like the one we built previously) face significant challenges when processing images. First, they ignore spatial structure; treating a pixel at coordinate (0,0) and (0,1) as completely independent inputs involves losing valuable contextual information. Second, they suffer from a parameter explosion. Connecting a standard 1000x1000 pixel image to a hidden layer of just 100 neurons would require 100 million weights, making training computationally prohibitive and prone to overfitting.

1.1 Biological Inspiration: The Visual Cortex

CNNs are inspired by the architecture of the biological visual cortex. In the late 1950s, researchers David Hubel and Torsten Wiesel discovered that neurons in the visual cortex have a small local receptive field, meaning they only react to visual stimuli in a specific, limited region of the visual field.

Some neurons fire only when they see vertical lines, others horizontal lines, and others still at specific angles. Modern CNNs mimic this by using small filters that "scan" the image for local patterns before aggregating them into complex objects.

1.2 The Mechanics: Filters and Convolutions

A CNN uses a Filter (or Kernel)—a small matrix, typically 3x3 or 5x5. This filter slides across the image, performing element-wise multiplication and summation. The result is a Feature Map, which highlights where specific patterns (edges, textures) occur.


Figure 1: Convolution Operation. A 3x3 filter slides across the input image to produce feature maps.

1.3 Stride and Padding

Control of the output dimensions is managed by two critical hyperparameters:

  • Stride ($S$): The distance the filter moves at each step. A stride of 1 moves one pixel at a time. A stride of 2 skips a pixel, effectively halving the output width and height.
  • Padding ($P$): Because filters have width, they "lose" pixels at the edges of an image.
    • VALID Padding: No padding is used. The output is smaller than the input.
    • SAME Padding: Zeros are added around the border so the output size matches the input size.
Math Foundation: Calculation Output Size
To calculate the output dimension ($O$) of a layer, use this formula:
$$ O = \lfloor \frac{W - K + 2P}{S} \rfloor + 1 $$
Where $W$ is input size, $K$ is kernel size, $P$ is padding, and $S$ is stride.

1.4 Pooling (Downsampling)

Once features are detected, exact location becomes less important than relative position. Pooling layers reduce the spatial dimensions of the feature maps, typically by keeping only the maximum value in a small window (Max Pooling).


Figure 2: Max Pooling Operation. A 2x2 window slides across the feature map, keeping only the maximum value to reduce spatial dimensions.

1.5 The Unified Block: Conv, ReLU, Pool

A standard CNN layer is actually a functional unit consisting of three steps:

  • Convolution: Feature extraction (linear).
  • ReLU: Activation (non-linear).
  • Pooling: Spatial reduction.

A network learns deep features by stacking these blocks: Level 1 finds edges $\to$ Level 2 finds shapes $\to$ Level 3 finds objects.

2. Deep Computer Vision with Keras

Now that we understand the theory, we can implement these components efficiently using the high-level Keras API.

2.1 Image Data Dimensions (Channel-Last)

TensorFlow and Keras use the Channel-Last convention:

  • Grayscale Image: [Height, Width, 1]
  • Color Image: [Height, Width, 3]
  • Batch of Images: [BatchSize, Height, Width, Channels]

2.2 The Conv2D Layer

In Keras, the convolution operation is handled by layers.Conv2D.

from tensorflow.keras import layers

# Creating a Convolutional Layer
conv_layer = layers.Conv2D(
    filters=32,            # Number of feature maps to output
    kernel_size=(3, 3),    # Size of the sliding window
    padding='same',        # Keep output size same as input
    activation='relu',     # Apply ReLU directly
    input_shape=(28, 28, 1) 
)
Code Breakdown:
filters=32 — the layer will learn 32 different patterns simultaneously.
kernel_size=(3, 3) — standard filter size.
padding='same' — tells Keras to add zero-padding so the image doesn't shrink.
activation='relu' — non-linearity used to detect complex features.

2.3 The MaxPooling2D Layer

# Creating a Max Pooling Layer
pool_layer = layers.MaxPooling2D(
    pool_size=(2, 2)       # Reduces spatial dimensions by half
)
Code Breakdown:
pool_size=(2, 2) — looks at 2×2 blocks and keeps only the maximum value, reducing the data by 75%.

2.4 Flatten & Dense Layers

flatten_layer = layers.Flatten()
dense_layer = layers.Dense(10, activation='softmax')
Key Insight — The Bridge Between Spatial and Linear:
layers.Flatten() collapses every value in the 3D feature volume into a single long 1D array. If your last pooling layer outputs shape [5, 5, 16], Flatten produces a vector of length 5×5×16 = 400. The subsequent layers.Dense(10, activation='softmax') treats each of those 400 values as an independent feature and learns a weighted vote for each of the 10 digit classes.

This repeated pattern (Conv -> ReLU -> Pool) allows the network to learn increasingly abstract representations. The first block might find "Edges"; the second block finds "Shapes" (circles, squares); the third block finds "Objects" (eyes, wheels).


Figure 3: Hierarchical Feature Learning. CNNs learn increasingly complex features: Level 1 detects edges, Level 2 detects shapes, Level 3 detects objects.

3. Understanding Shapes: The Flow of Tensors

The #1 error beginners face in TensorFlow/Keras is a Shape Mismatch. You must understand how the dimensions of your data change as it flows through the network.

3.1 The Transformation Chain

Imagine we are processing a standard MNIST image (Grayscale, 28x28 pixels).
1. Input: [1, 28, 28] (1 Channel, 28 Height, 28 Width).
2. Pass through Conv Layer (k=5, padding="same"): The number of channels increases (we find multiple features), but the height/width stays roughly the same. -> [28, 28, 6] (6 Feature Maps).
3. Pass through Pool Layer (2x2): The spatial dimensions are cut in half. -> [14, 14, 6].
4. Repeat: Another Conv/Pool block might take us to -> [5, 5, 16].

3.2 The Flattening Problem

At the end of the feature extraction, we have a 3D volume of data (5 height x 5 width x 16 channels). But our final Classifier (Fully Connected Layer) expects a flat list of numbers (a 1D Vector).
Before we can classify, we must Flatten the tensor:
$$ 16 \times 5 \times 5 = 400 $$
Our 1D Vector will have a length of 400. This is why you will see layers.Flatten() in the code. If you calculate this number wrong, your code will crash.

4. The Architecture: LeNet-5

Proposed by Yann LeCun in 1998, LeNet-5 is the foundational architecture of modern computer vision. It was originally designed to recognize handwritten zip codes on mail.

The architecture follows a funnel-like structure. It begins with Convolutional Layers to extract features, followed by Pooling Layers to compress the data. This process is repeated to extract higher-level features. Finally, the spatially compressed feature maps are flattened into a 1D vector and passed through Fully Connected Layers to perform the final classification. We will implement this classic structure—Conv, Pool, Conv, Pool, Linear, Output—to solve the MNIST classification problem.


Figure 4: LeNet-5 Architecture. The network processes a 28x28 input image through convolutional and pooling layers, then flattens and classifies via fully connected layers to output 10 class predictions.

ReLU Mechanic: Mathematically, the derivative of ReLU is 1 for positive inputs and 0 for negative inputs, which explains both its efficiency and the risk of "dead neurons".
